PowerRename图片强制统一重命名操作教程

发表于2026-10-25|更新于2026-10-25

只要你按照下面的步骤一字不差地照着做，就能把电脑里乱七八糟的图片，瞬间变成整齐划一的“纯英文+数字”格式。

准备工作

  1. 选中你需要重命名的所有图片（可以按 Ctrl + A 全选）。
  2. 右键点击这些图片，选择 PowerRename（或者在 Windows 11 的右键菜单“显示更多选项”里找）。
  3. 打开界面后，直接对照下方的内容，复制粘贴，并检查勾选项。

参数设置清单（严格对照）

为了不出现误解，请逐一核对你的界面，必须和下面完全一样：

1. 左上角：搜索框

  • 操作：复制并粘贴这一串字符 👉 .* （注意：是一个英文句号 . 紧挨着一个星号 *，绝对不能有空格）。
  • 作用：这代表选中原来的整个文件名（包括“下载”、“微信图片”等所有乱码）。

2. 勾选框（核心关键）

  • ✅ 使用正则表达式：必须打勾。（如果不打勾，上一步的 .* 就失效了）
  • ⬜ 匹配所有出现的对象：必须取消打勾。（留空）
  • ⬜ 区分大小写：必须取消打勾。（留空）

3. 中间：替换框

  • 操作：复制并粘贴这一串字符 👉 Image_${padding=3}
  • 作用：Image_ 是你想要的英文前缀（生成后就是 Image_000, Image_001…）。${padding=3} 是告诉软件，数字要补齐到 3 位数（001, 002）。
    • 注：如果你想换个词，就把 Image_ 改成 Pic_ 或 Photo_，后面的 ${padding=3} 绝对不要动。

4. 下方：应用于

  • 操作：下拉菜单选择 “仅文件名”。
  • 作用：这样只会修改点 . 前面的名字，完美保留 .jpg 或 .png 后缀，图片不会被损坏。

5. 最下方：格式与数据源

  • 文本格式：点击左边第一个蓝色的 aa 图标。（确保它亮起，这代表保持小写）。
  • 替换所用时间：下拉选择 “创建时间”。
  • 用于替换的元数据源：下拉选择 “EXIF 元数据”。（这两个选项其实在你当前这个规则下不起作用，但保持默认即可，不用动）。

效果预览与执行

设置完上述内容后，绝对不要马上点应用！

请你转头看向界面的 右侧区域，那里有两列：

  • 左列是【原始】：下载 (1).jpg
  • 右列是【已重命名】：image_000.jpg

你需要检查右侧的预览效果，确认：

  1. 原来的“下载”、“(1)”等中文和符号是不是全部消失了？
  2. 是不是全部变成了 image_000.jpg、image_001.jpg 这种纯英文加数字的格式？

只要右侧预览和上面描述的一致，直接点击右下角的蓝色【应用】按钮即可！ 几十张杂乱无章的图片瞬间就会变得极度舒适。

灵魂防翻车提示

  1. 如果点完应用发现排错序了怎么办？
    按住键盘上的 **Ctrl + Z**，所有的图片会瞬间恢复成原来的乱名，你可以重新调整文件排序后再来一次。
  2. 想从 1 开始而不是从 0 开始？
    PowerRename 默认从 0 开始排。如果你不能接受 000，可以在应用完成后，再全选一次，用同样的方法搜 image_ 替换成 1image_（但没必要，000 也很整齐）。
  3. 如果你的图片后缀名丢了（比如变成了 .png 你想保留，但发现也变了），那是因为在“应用于”那里选错了，必须选“仅文件名”。
