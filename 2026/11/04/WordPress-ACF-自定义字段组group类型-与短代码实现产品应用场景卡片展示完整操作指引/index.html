WordPress ACF(自定义字段组group类型)与短代码实现产品应用场景卡片展示完整操作指引

发表于2026-11-04|更新于2026-11-04|wordpress

在 B2B 独立站（如机械设备类）的产品详情页中，展示“应用场景”能有效帮助客户对号入座，提升询盘转化率。本文将详细说明如何使用 WordPress 的 ACF（Advanced Custom Fields）插件与自定义短代码，实现后台富文本录入、前台背景图与遮罩层渲染、整个卡片可点击跳转，且支持自动适应列数（PC 端填几个铺满几个，移动端强制两列）的完整流程。

一、后台配置 ACF 字段组

为了让编辑人员可以灵活上传图片、输入标题、副标题以及添加链接，我们需要在 ACF 中创建一个包含富文本编辑器的组字段。

  1. 进入 WordPress 后台，点击 ACF > 字段组 > 添加新建。
  2. 标题 填写：Applications （此处为字段组名称）。
  3. 点击 添加字段：
    • 字段标签：Application
    • 字段名称：lier_applications
    • 字段类型：选择 Group（组）。
  4. 在 Group 字段下，点击 添加字段 创建子字段。子字段必须全部为 WYSIWYG 编辑器（富文本编辑器），建议建立 4 个，名称分别如下：
    • 字段 1：application_scenarios_one
    • 字段 2：application_scenarios_two
    • 字段 3：application_scenarios_three
    • 字段 4：application_scenarios_four
  5. 保存字段组，并在 位置规则 中设置显示于 文章类型 = 产品 (Product)。

二、后台内容录入规范

在编辑具体产品时，应用场景的录入方式直接影响前端的呈现效果。在每个 WYSIWYG 编辑器中，请按以下顺序操作：

  1. 点击 Add Media（添加媒体），插入一张场景图。
  2. 敲击回车，输入场景的标题（如 Seafood Processing），并可以在编辑器中将其设为标题（H3 或 H4）。
  3. 敲击回车，输入场景的副标题或简短描述。
  4. 添加链接（可选）：选中需要加链接的文字，点击添加链接，填入目标 URL。
    • 注意：只要这个富文本区域内包含一个 <a> 标签，前端程序就会自动提取该链接，使整个卡片都变为可点击状态。如果没有添加链接，卡片则不可点击。
