不同类型的请求及其作用,API的分类

发表于2022-08-13|更新于2026-09-12|大前端

不同类型的请求及其作用：

  • GET：从服务器端读取数据
  • POST：向服务器端添加新数据
  • PUT：更新服务器端已经存在的数据
  • DELETE：删除服务器端数据
REST API: restful

  • 发送请求进行CRUD哪个操作由请求方式来决定

  • 同一个请求路径可以进行多个操作

  • 请求方式会用到GE/POST/ PUT/DELETE

2.非 REST API: restless
  • 请求方式不決定请求的CRUD操作
  • 一个请求路径只对应一个操作
  • 一般只有GET/POsi
提示：

1，REST API 又叫 restful，非 REST API 又叫 restless；
2，CRUD：代表着增删改查操作；
3，REST 和 非REST 的区别就是一个接口请求方式的不同，后台数据库可以进行不同的操作；
